# Customer portraits

These seven fictional customer portraits were generated for Bikegame with the
built-in OpenAI image generation tool. They use a consistent hand-painted,
low-poly portrait direction designed to remain readable in the delivery HUD at
small sizes.

Characters:

- Marta Zielińska — garden designer
- Leon Novák — architecture student
- Amina Okafor — night-shift doctor
- Erik Lund — harbour engineer
- Mei Tanaka — violin teacher
- Samira Haddad — radio producer
- Elin Sørensen — Meadowcroft farmer

The production prompt specified a square head-and-shoulders composition, simple
opaque painterly backdrop, softly faceted forms, natural proportions, no text,
and no watermark. Each follow-up portrait used Marta's image only as a visual
style reference while explicitly requesting a different identity, wardrobe,
hair, and palette.
