# CC0 material sources

The 1K PBR maps in this directory are redistributed under Creative Commons CC0:

- `facade/`: ambientCG **Plaster 001**, 1K JPG
  - https://ambientcg.com/view?id=Plaster001
- `roof/`: ambientCG **Roofing Tiles 014 A**, 1K JPG
  - https://ambientcg.com/view?id=RoofingTiles014A
- `stone/`: Poly Haven **Stone Tile Wall**, 1K JPG
  - https://polyhaven.com/a/stone_tile_wall
- `road/asphalt_*`: Poly Haven **Clean Asphalt**, 1K JPG
  - https://polyhaven.com/a/clean_asphalt
- `road/cobble_*`: ambientCG **Paving Stones 141**, 1K JPG
  - https://ambientcg.com/view?id=PavingStones141

Only color, OpenGL normal, and roughness maps are included. Attribution is not
required by CC0, but the source list is retained for provenance and upgrades.

`facade/weathered_plaster_color.png` is an original generated game texture made
for this project. It uses the user's Cornwall and Prague photography only as
material, ageing, and palette reference; it does not reproduce a photographed
building. Existing CC0 plaster normal and roughness maps provide its surface
response.
