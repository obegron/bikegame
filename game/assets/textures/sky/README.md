# Sky texture

`evening_road_01_pure_sky.png` is the 4096×2048 tonemapped panorama used by
the MIT-licensed
[2Retr0/GodotOceanWaves](https://github.com/2Retr0/GodotOceanWaves) demo.
The original asset is
[Evening Road 01 (Pure Sky)](https://polyhaven.com/a/evening_road_01_puresky)
by Jarod Guest and Sergej Majboroda, published by Poly Haven under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

Bikegame samples the panorama only for detailed cloud structure. The dynamic
sky shader supplies its own time-of-day colors, moving sun, moon, stars, and
cloud lighting.
